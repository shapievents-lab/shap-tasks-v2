# Shap Tasks v2

מערכת ניהול המשימות הפנימית של Shap Productions. Next.js (App Router) + Postgres.

## הרצה מקומית

```bash
npm install
DATABASE_URL=postgres://... npm run dev
```

הסכימה נוצרת אוטומטית בהרצה הראשונה (ר' lib/db.ts).
